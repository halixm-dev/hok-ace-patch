# The allowlist is the only gate for translating a config bin

Translating a config bin can blank a screen, remove a button or crash a match, so a config bin is translated only once a device cycle has cleared it onto the allowlist. The source fork's row-checksum heuristic (`pb_text.has_row_checksum`) was measured as a replacement and dropped: on a pristine layer it answers true for the withdrawn bins and for the ones the allowlist used to translate alike, and an earlier reading that seemed to separate them came from our own patched layer, whose rewrite had invalidated the stored checksum. Evidence: [prime-only-append.md, journey log item 2 and Out of Scope](../features/prime-only-append.md#s3-out-of-scope), [extra-text-cycles.md](../features/extra-text-cycles.md) and [lab notebook §5 (2026-09-30)](../lab-notebook.md#5-the-extra_text-allowlist).
