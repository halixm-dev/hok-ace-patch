# Write the translation only after the in-game update

Tencent's updater patches packages with binary diffs against their original contents, so a package we changed before the update finishes breaks the diff, and the game's repair cannot converge on a package it does not recognise (every diff fails CRC, `errorCode:361`). A run therefore writes the translation only once the in-game update has completed, onto a complete override layer; a data set caught mid-update is also the measured cause of one startup crash.
